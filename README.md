# Unser Reiseplaner – Version 1.2.0

Version 1.2.0 macht **Entdecken** zum eigentlichen Einstieg in die Reiseplanung.

## Neuer Planungsfluss

1. Reiseziel und Zeitraum anlegen.
2. Unter **Entdecken** Städte, Natur-/Landes-Highlights und Wildlife ansehen.
3. Interessante Vorschläge mit einem Häkchen in die Wunschliste übernehmen.
4. Für jeden Wunsch die Priorität **Muss / Hoch / Mittel / Optional** festlegen.
5. **Routenvorschlag erstellen** wählen.
6. Die App erzeugt eine neue, unabhängig bearbeitbare Reiseversion mit:
   - geografisch geordneten Stopps,
   - Unterkunfts-Platzhaltern,
   - Langstrecken-Verbindungen,
   - Transfers,
   - erster zeitlicher Einordnung,
   - sichtbaren offenen Punkten.
7. Im Planer werden die gelb markierten Platzhalter nach und nach konkretisiert, z. B. tatsächliches Hotel, Flugnummer, Zugnummer, Anbieter oder Transferdetails.

## Wichtig

Der automatische Routenvorschlag ist ein **Planungsentwurf**, keine Buchungsmaschine. Kostenlose öffentliche Datenquellen reichen nicht aus, um weltweit verlässlich konkrete zukünftige Flug-/Zugfahrpläne, Hotels oder ÖPNV-Verbindungen automatisch zu buchen. Deshalb werden solche Angaben bewusst als offene Bausteine erzeugt und klar markiert.
